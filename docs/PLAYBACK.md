# 演奏与操作

首次启动见 [安装方法](../README.md#安装方法)。导入、新增和联网更新曲谱见 [曲库管理](LIBRARY.md)。

## 开始演奏

1. 在左侧选曲。解析完成后，列表下方显示当前速度下可演奏的音符数、预计时长和实际移调量。
2. 首次使用先保持「仅测试」开启，点击「播放」确认时间轴和进度正常。
3. 在 Windows 游戏内实奏时，确认启动日志显示「运行权限：管理员」且急停热键 `Shift+F8` 注册成功。装备口琴并核对状态栏的游戏进程名。
4. 关闭「仅测试」，点击「播放」、双击曲目或按 `Shift+F9`。利用 3 秒倒计时切回游戏并打开口琴界面。
5. 用 `Shift+F10` 暂停或继续，用 `Shift+F8` 或「停止」结束。倒计时、等待游戏、演奏和暂停期间，曲库与播放设置暂时锁定。

## 演奏参数

| 设置 | 行为 |
|---|---|
| 速度 | 50%–200%。倍速可能缩短音符的可用时间，过短的音符会跳过并计数。 |
| 移调 | 手动范围为 −12 到 +12 半音。自动适配默认开启，在手动偏移后补充整体移调。 |
| 循环 | 保留曲末休止，整首结束后等 0.8 秒再开始。 |
| 仅在游戏窗口位于前台时演奏 | 默认开启。倒计时结束后等待并绑定匹配的窗口。失去焦点时暂停，回到同一窗口后继续。 |
| 游戏进程关键字 | 默认 `DeltaForce`，按实际进程名做不区分大小写的子串匹配。开启前台保护时必须填写。 |
| 仅测试 | 默认开启，按曲谱走时间轴。macOS 和 Linux 固定使用此模式。 |

右侧显示播放进度、当前按键和日志。底部状态栏显示播放状态、前台进程匹配结果和运行权限。暂停、停止或退出时，播放器会释放本次演奏按下的键。

## 迷你浮窗

点击主窗口右上角的「迷你浮窗」或按 `F11` 打开置顶窗口。浮窗显示曲名、状态与进度，也可以控制播放。点击「主窗口」返回完整界面。

点击「选曲」后滚动并点选曲谱。播放中选另一首曲子会先停止当前播放，再切换曲目。切换完成后点击「播放」开始。点选当前曲目时会继续当前的播放状态。

浮窗透明度为 0%–65%，默认 15%。向右拖动更透明。主窗口对应的不透明度为 35%–100%，默认 85%。拖动浮窗空白处可以调整位置，位置与透明度会在下次打开时恢复。

## 全局热键

| 热键 | 功能 |
|---|---|
| `Shift+F9` | 播放或停止 |
| `Shift+F10` | 暂停或继续 |
| `Shift+F8` | 急停并释放演奏按键 |
| `F11` | 切换主窗口和迷你浮窗。Windows 优先注册为全局热键，全局热键不可用时可以在主窗口内使用。 |

演奏热键采用固定绑定。热键注册和急停的实现见 [设计文档](DESIGN.md#11-热键设计)。

## 常见问题

### 游戏里没有反应

确认播放器以管理员身份启动，游戏和播放器使用相同权限。打开游戏里的口琴界面，切换到英文输入法并使用无边框窗口。演奏时请避免手动按 `Z`–`M`。如果仍无响应，先用「仅测试」确认播放进度，再查看日志中的 `SendInput` 错误。

### 热键失效

日志会显示热键注册结果。关闭占用热键的程序后重启播放器。`Shift+F8` 注册成功后才能实奏。如果 `F11` 不可用，从主窗口点击「迷你浮窗」。

### 前台进程匹配失败

根据底部状态栏显示的实际进程名更新关键字，例如 `DeltaForceClient`。启用前台保护时，空关键字会阻止开始演奏。

### 音符被跳过或移调量与设置不同

每个音符换算到实际速度后至少需要 72ms。降低速度可减少密集音符的跳过数量。日志中的移调量包含自动适配，关闭自动适配即可只用手动值。详见 [曲谱与演奏规则](SCORE_FORMAT.md)。

### 平台与功能限制

游戏实奏输入使用 Windows `SendInput`。macOS 和 Linux 提供「仅测试」模式。播放器目前没有选轨、曲谱试听、播放列表和节拍器功能。
