# 图片曲谱键位版

从四张社区单音曲谱图转录的 32 首曲目。原图只标音高和换气位置，没有时值；
这里保留游戏键位，红色高音记作 `↑`，绿色低音记作 `↓`。
可直接照着在游戏里弹；带节奏的完整版本见 `scores/图片曲谱/` 下的同名 TXT。

键位与音高：`Z`=do、`X`=re、`C`=mi、`V`=fa、`B`=sol、`N`=la、`M`=si。
空格/逗号/竖线表示原谱的换气或乐句分隔。
