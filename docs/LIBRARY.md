# 曲库管理

当前内置 32 首 TXT 曲谱，包含《小星星》示例、简谱转录和 MIDI 主旋律转写。

## 添加曲谱

在主窗口左侧点击「添加曲谱…」选择文件，也可以把 `.txt`、`.mid` 或 `.midi` 文件拖入窗口，或手动放入程序旁的 `scores/` 目录后点击「刷新」。程序导入时会复制文件，遇到已有同名文件会在日志中提示并保留原文件。

自制简谱和 MIDI 的文件要求见 [曲谱与演奏规则](SCORE_FORMAT.md)。准备好曲谱后，按 [演奏与操作](PLAYBACK.md) 试奏。

## 检查更新

1. 点击曲库上方的「检查更新」。Windows 打包版优先读取 GitHub 最新 Release，发现更高版本时下载完整程序包。
2. 完整更新包按文件大小和 SHA-256 校验，并检查 EXE、运行依赖、版本标记及 ZIP 路径安全。确认安装后，程序退出，由 Windows PowerShell 助手将旧目录备份、替换为新目录并重启。
3. 完整更新保留清单外的本地曲谱和既有备份；本地同名文件会从新 Git 清单移除，以后仍按本地曲目保护。Git 清单内的内置曲谱使用新包版本。播放速度、移调、浮窗位置等 QSettings 设置不受影响。
4. 没有更高程序版本或 Release 尚未提供 Windows 包时，播放器读取 GitHub `main` 分支的 `scores/`，显示新增或有变更的曲谱。确认后下载并核对 Git blob 校验值，再逐首试解析；被替换文件备份到 `scores/.update-backups/`。

`scores/.git-scores.json` 记录 Git 内置曲目。清单内的同名曲谱会随更新覆盖。清单外的同名本地谱会被跳过或保留，日志中会列出这些曲目。新增的 Git 曲谱安装后会自动登记。编辑内置曲目时，可另存为不同文件名以保留自己的版本。

源码运行模式只更新曲谱，不会覆盖源码目录。旧版 v1.0 需先手动安装一次 v1.1.0 或更高版本，才能使用完整程序自动更新。 [Windows 打包步骤](DEVELOPMENT.md#打包为-exe) · [更新器的校验和回滚](DESIGN.md#64-联网曲库更新)

## 当前曲谱版本

- 《富士山下》从人声段开始，《我好想你》展开了两遍反复，《海阔天空》按 MIDI 主旋律轨转写。
- 《一生所爱》《吻别》《烟花易冷》等 16 首有中间小节的时值与谱头标注的拍号不符。它们均可在原速下试奏，节奏还需对照原谱复核。
- [图片曲谱键位版](图片曲谱_键位版.md) 保存了早期图片转录的键位资料。配套生成工具见 [开发与打包](DEVELOPMENT.md#图片键位谱生成工具)。
