# 曲库管理

当前内置 32 首 TXT 曲谱，包含《小星星》示例、简谱转录和 MIDI 主旋律转写。

## 添加曲谱

在主窗口左侧点击「添加曲谱…」选择文件，也可以把 `.txt`、`.mid` 或 `.midi` 文件拖入窗口，或手动放入程序旁的 `scores/` 目录后点击「刷新」。程序导入时会复制文件，遇到已有同名文件会在日志中提示并保留原文件。

自制简谱和 MIDI 的文件要求见 [曲谱与演奏规则](SCORE_FORMAT.md)。准备好曲谱后，按 [演奏与操作](PLAYBACK.md) 试奏。

## 检查更新

1. 点击曲库上方的「检查更新」。播放器读取 GitHub `main` 分支的 `scores/`，显示新增或有变更的曲谱。
2. 确认安装后，播放器先下载并核对文件大小和 Git blob 校验值，再逐首试解析。全部校验通过后才安装。
3. 更新完成后曲库会自动刷新。被替换的内置文件备份到 `scores/.update-backups/`，日志会显示备份路径。

`scores/.git-scores.json` 记录 Git 内置曲目。清单内的同名曲谱会随仓库更新。清单外的同名本地谱会被跳过，日志中会列出这些曲目。新增的 Git 曲谱安装后会自动登记。编辑内置曲目时，可另存为不同文件名以保留自己的版本。

联网更新范围为曲谱和归属清单。程序功能变更需要更新源码或重新打包。 [Windows 打包步骤](DEVELOPMENT.md#打包为-exe) · [更新器的校验和回滚](DESIGN.md#64-联网曲库更新)

## 当前曲谱版本

- 《富士山下》从人声段开始，《我好想你》展开了两遍反复，《海阔天空》按 MIDI 主旋律轨转写。
- 《一生所爱》《吻别》《烟花易冷》等 16 首有中间小节的时值与谱头标注的拍号不符。它们均可在原速下试奏，节奏还需对照原谱复核。
- [图片曲谱键位版](图片曲谱_键位版.md) 保存了早期图片转录的键位资料。配套生成工具见 [开发与打包](DEVELOPMENT.md#图片键位谱生成工具)。
