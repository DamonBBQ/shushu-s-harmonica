# 曲谱与演奏规则

播放器支持 UTF-8 简谱 TXT 和标准 MIDI。输入会映射为适合游戏口琴的单音时间轴。曲谱的导入、更新与内置版本见 [曲库管理](LIBRARY.md)。

## 简谱 TXT 格式

下面是带 `GRID` 的简谱示例。

```text
TITLE=小星星（片段）
BPM=100
GRID=4

1--- 1--- 5--- 5--- |
6--- 6--- 5------- |
```

| 记号 | 含义 |
|---|---|
| `TITLE=` | 曲名。省略时使用文件名。 |
| `BPM=` | 每分钟四分音符数，默认 100。有限数值会限制在 20–300 并取整。 |
| `GRID=` | 一拍的时值格数，默认 1，可设为 1–16 的整数。`GRID=4` 时每格为四分之一拍。 |
| `1`–`7` | 自然音级，以 `1=C4`（MIDI 60）为基准。 |
| `0` | 休止。 |
| `8` 或 `i` | 高音 Do，相当于 `^1`。 |
| 前缀 `b`、`^`、`#` | 分别表示降八度、升八度、升半音。八度前缀可叠加，例如 `bb1`。前缀也可组合，例如 `^#1`。 |
| 后缀 `-` | 每个横线增加一格。单独的 `-` 延长前一个音或休止一格。 |
| `//`、`\|` | 分别标记注释和小节分隔。分隔符本身占零格。 |

`b5` 是低音 Sol，`5-` 是持续两格的中音 Sol。`GRID=4` 时，`5---` 占一拍。音符和休止都计入拍数。4/4 的完整小节占 16 格，3/4 占 12 格。弱起和结尾根据谱上的实际时值记谱。

无法识别的记号会报告行号和原记号。带 `@format` 的文本谱或键位谱需要先转为标准 MIDI 或这里的 TXT 格式。

在 100% 速度下检查可演奏音符数和跳过数量，再对照同一版本的旋律、起拍、延音和休止试听。通过播放器检查表示时值和音域符合其输入要求。

## MIDI 处理规则

- 支持 PPQ 计时的 Type 0 / Type 1。Type 2 与 SMPTE 计时会报告错误。原始 MIDI 只读，不会在 `scores/` 中生成衍生文件。
- 跳过打击乐通道（通道 10，从 0 编号时为 9）。`note_on` 且 velocity 大于 0 算作按下，`note_off` 或 velocity 为 0 的 `note_on` 算作松开。
- 各轨的 tick 先累加为绝对时间，再共用速度变化时间轴；按流、音高匹配按下与松开。重复按下时先结算上一个音，文件结束仍按住的音按 0.5 秒收尾。曲谱长度保留轨道末尾的休止。
- Type 0 按非打击乐通道拆成虚拟流；Type 1 按 `(轨道, 通道)` 拆流。不会把不同流直接合并后再选最高音。
- 每个候选按音符数量与密度、单音比例、最大复调、音区与音域、时值、起音规律、旋律轮廓、乐句覆盖、重复伴奏模式、轨道名和 GM 乐器评分。排名最高且分差明确的候选自动作为旋律。
- 置信度同时考虑绝对质量与第一、第二候选的分差。高置信度直接使用；中置信度显示提示；低置信度建议手动确认。启发式结果不保证等同于原曲人声，复杂编曲应使用「MIDI 声部…」核对。
- 只对所选流单音化：同一起点取最高音，后续起音会截断前一个重叠音，时值不超过下一音起点。其他伴奏流不参与这一次单音化。
- 默认修复短音：小于 72ms 的音在下一音前仍有空间时延长到最多 80ms，并保留 10ms 间隙；小于 25ms 的音同时计为装饰音。下一音过密而无法修复的数量会显示在曲谱信息中，播放器仍可能按实际速度跳过这些音。
- 手动声部覆盖保存在当前歌曲偏好中，并绑定 MIDI 的 SHA-256。文件内容变化后旧覆盖自动失效。Git 内置曲目与本地同名曲目的偏好仍相互独立。
- 缓存键包含 SHA-256、预处理算法版本和选项指纹，位置在系统 AppData，不进入曲库。解析使用与哈希相同的内容快照；缓存损坏、字段缺失或声部语义不一致时自动重新解析。
- 「旧版合并」保留兼容行为：合并所有非打击乐流，把起音相差小于 30ms 的音归簇，保留最高音和同簇备选音；适合临时排查，不再作为自动模式。

## 键位与音域映射

| 音级 | 1 (Do) | 2 (Re) | 3 (Mi) | 4 (Fa) | 5 (Sol) | 6 (La) | 7 (Si) | 高音 Do |
|---|---|---|---|---|---|---|---|---|
| 按键 | `Z` | `X` | `C` | `V` | `B` | `N` | `M` | `,` |
| 扫描码 | 0x2C | 0x2D | 0x2E | 0x2F | 0x30 | 0x31 | 0x32 | 0x33 |

鼠标左键降八度，右键升八度，中键升半音。游戏口琴覆盖 MIDI 48–85（C3–C#6）。

| MIDI 范围 | 音区 | 组合方式 |
|---|---|---|
| 48–59 | C3–B3 | `Z`–`M` 加左键 |
| 60–71 | C4–B4 | `Z`–`M` |
| 72 | C5 | `,` |
| 73 | C#5 | `,` 加中键 |
| 74–83 | D5–B5 | `X`–`M` 加右键 |
| 84 | C6 | `,` 加右键 |
| 85 | C#6 | `,` 加右键和中键 |

C#5 和 C#6 使用上表的专用组合。其余升半音使用下方自然音键加中键，并叠加对应八度的鼠标修饰键。例如，C#3 用 `Z`、左键和中键，A#5 用 `N`、右键和中键。扫描码和鼠标事件的实现见 [设计文档](DESIGN.md#9-输入层设计)。

## 移调与音域适配

- 自动移调在手动偏移后，从 ±30 半音内选择落进 MIDI 48–85 的可演奏音符最多的方案。数量相同时取绝对值较小的自动偏移。
- 手动与自动移调叠加，实际应用值显示在曲谱信息与演奏日志中。
- 超出音域的音符按 ±12 半音折返，可保留音级，实际演奏的八度可能变化。最高区只覆盖 C6 与 C#6。

## 节奏与时序模型

播放器按曲谱的起点、时值和播放速度计算按键时间。音键在实际起点后的 12ms 按下，在实际终点前 20ms 松开。

| 项目 | 时间 |
|---|---|
| 修饰键预备 | 12ms |
| 音键最短保持 | 40ms |
| 尾部留白 | 20ms |
| 最短可演奏时长 | 72ms |

修饰键先于音键按下，音键松开后再逆序释放修饰键。每个音符都完整按下和松开。调度迟到时会用尾部留白吸收延迟，容纳不了最短保持时间的音符会跳过，后续音符仍按原时间轴调度。

手动暂停或失焦时释放按键。继续时从被打断的音符起点重播，两音之间暂停时保留原有的剩余间隔。曲末休止计入曲长，循环在时间轴完成后再等 0.8 秒。调度实现见 [设计文档](DESIGN.md#8-时序与调度层设计)。
